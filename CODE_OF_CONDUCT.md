# Code of Conduct

## Our commitment

Slipstream Extended is a privacy-sensitive health-data project. Contributors,
maintainers and users must make participation welcoming, respectful and safe,
regardless of background, identity, experience or ability.

## Expected behavior

- Be constructive, patient and specific.
- Respect personal boundaries and differing levels of technical experience.
- Protect other people's identities, credentials and fitness data.
- Accept correction gracefully and focus criticism on the work.
- Never pressure anyone to publish private health or account information.

Harassment, discrimination, threats, sexualized attention, deliberate exposure
of private information and sustained disruptive behavior are not acceptable.

## Privacy in reports

Do not post Garmin data, email addresses, account identifiers, access assertions,
tokens or private logs in an issue or pull request. Use synthetic or redacted
examples whenever possible.

## Enforcement

Maintainers may edit or remove contributions, restrict participation or ban an
account when behavior violates this code. Decisions should be proportionate,
documented privately and made without retaliation.

To report conduct privately, use **Security → Report a vulnerability** in the
GitHub repository and begin the title with `Conduct report`. The channel is used
only to keep the report confidential; do not include unrelated secrets or health
data. Security vulnerabilities should be reported as described in
[SECURITY.md](SECURITY.md).

This code applies in project spaces and whenever someone publicly represents the
project.
