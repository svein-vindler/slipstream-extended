# Triage labels

Map the five canonical roles from mattpocock/skills to these exact GitHub label names.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | More information needed |
| ready-for-agent | ready-for-agent | Specified for an agent; execution still requires task authorization |
| ready-for-human | ready-for-human | Human work or decision needed |
| wontfix | wontfix | Will not be actioned |

Use this mapping when a skill names a triage role. Labels describe readiness; they do not grant permission to change code, publish, merge, deploy or access production. Apply or change labels only within an authorized tracker task. Preserve existing labels and their metadata.
